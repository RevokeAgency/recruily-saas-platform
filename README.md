# Dashboard-Vorschau (HTML)

`dashboard-preview.html` ist ein Schnappschuss von `/dev/dashboard-preview`
mit erfundenen Beispieldaten. Eine einzelne Datei, Schriften, Logo und
Styles sind eingebettet, es wird nichts aus dem Netz geladen.

**Öffnen:** Datei auf GitHub anklicken, oben rechts „Download raw file“,
dann die heruntergeladene Datei per Doppelklick im Browser öffnen.

Neu erzeugen: auf `main` den Server starten und die Route aufrufen, siehe
`app/dev/dashboard-preview/page.tsx`.
